# Little Me v0.3.0 — Life & Interaction
Fixed reference-derived house and characters. Native Android live wallpaper. This release improves sofa perspective and depth, distinct activity silhouettes, stair waypoints, companion behaviour, returning home, window/candle lighting and adds a manual activity preview selector. Wallpaper is artwork-only. Uses existing character sprites with crop/pose and procedural limb changes rather than a new rigged sprite pack. A fresh simulation state is used for the revised waypoint layout. Device visual validation is still required. GitHub CI compiles, tests and publishes the APK; debug signing may require reinstalling.
