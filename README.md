# Little Me v0.3.1 — Furniture & Motion
Native Android live wallpaper. Same house and reference-derived characters. Dedicated approach waypoints around furniture, terminal seating and sleeping destinations, timed sit/stand and jump transfers, furniture masks that clip only the current actor, and updated activity anchors. A new simulation state is used because waypoint coordinates changed. Animation uses the existing sprite art plus procedural transfers; visual collision masks and poses still require on-device verification. CI tests route connectivity, transitions, persistence and companion routines. Debug APKs may require reinstalling.

## v0.3.2 — Lively lock screen
Default wallpaper pacing: ordinary human activities 8–24 seconds, dog activities 5–18 seconds (longer for naps, outings and sleeping); walking takes normal time. Disable Lively lock screen in the app for original real-time pacing. Animation stops when Android marks the wallpaper invisible and catches up on return. The frame loop retries interrupted surfaces while visible. Samsung visibility and on-device animation remain to be validated. Existing v0.3.1 world state is retained and long timers capped when lively mode is enabled.

## v0.3.3 — A new scene on wake
Enabled by default, each screen-off/on cycle selects a visually distinct, already-settled activity scene before the next visible frame. Character placement happens offscreen only; normal animations and routing continue while visible. Time of day influences scene choice, and dog activities are paired with the human activity. The New scene on every wake switch disables this behaviour and restores continuous catch-up. Actual Samsung screen lifecycle remains to be tested; engine recreation may also select a fresh scene.

## v0.3.4 — Pose and anchor cleanup
Screenshot-driven adjustments to the sink, window, couch and dog anchors. The stretch masks the original arms before rendering raised sleeves; sofa backrest mask updated. Wallpaper fill uses the original artwork background color. Wake variety and existing routines remain. A new state store avoids old coordinates. Pixel-level alignment and stretch silhouette require on-device visual testing; this is not a new sprite pack.

## v0.4.0 — Little Us
Maddie joins as an independently animated, reference-inspired pixel character. The house is unchanged. Wake scenes now balance the least-seen eligible visual groups, randomly break ties and persist rotation counts; ordinary routines also reduce repetition. Independent and occasional shared sofa/table/bed scenes, dog interactions and arrival greeting routing. Presence setup is optional; Android local geofencing requires explicit location permissions. The optional private HTTPS relay and setup for Android or iPhone Shortcuts are in [relay/README.md](relay/README.md). No relay is deployed by this repository. Without presence configuration, unknown states use simulated routines. The derived Maddie artwork is procedural, not a photo or a fully redrawn matching sprite sheet; on-device visual validation is required. Location sharing must be voluntary, and the relay stores no location coordinates. Tests cover the four home/away combinations and activity fairness. The relay uses separate keys and expiring states. The existing wake/pace controls remain.
