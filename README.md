# Little Me v0.3.1 — Furniture & Motion
Native Android live wallpaper. Same house and reference-derived characters. Dedicated approach waypoints around furniture, terminal seating and sleeping destinations, timed sit/stand and jump transfers, furniture masks that clip only the current actor, and updated activity anchors. A new simulation state is used because waypoint coordinates changed. Animation uses the existing sprite art plus procedural transfers; visual collision masks and poses still require on-device verification. CI tests route connectivity, transitions, persistence and companion routines. Debug APKs may require reinstalling.

## v0.3.2 — Lively lock screen
Default wallpaper pacing: ordinary human activities 8–24 seconds, dog activities 5–18 seconds (longer for naps, outings and sleeping); walking takes normal time. Disable Lively lock screen in the app for original real-time pacing. Animation stops when Android marks the wallpaper invisible and catches up on return. The frame loop retries interrupted surfaces while visible. Samsung visibility and on-device animation remain to be validated. Existing v0.3.1 world state is retained and long timers capped when lively mode is enabled.
