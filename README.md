# Little Me v0.2.0

A fixed pixel-art home with a reference-derived bald, broad-built bearded character and small cream-and-tan dog. Native Android wallpaper simulation, offline.

- Original 309 × 553 artwork (no 96-pixel compression).
- Independent weighted routines, day/night and persistence while the display is off.
- Four-frame walking cycles and separate seated, washing, petting, dog sleeping, sitting and play poses; activity props and environmental animation.
- 16 human and 10 dog routines including gaming, dishes, sleeping, leaving home, working, painting miniatures, Magic cards and coordinated belly rubs.
- Demo mode shortens activities without accelerating walking; real time and manual next-activity controls available in preview.
- System-bar safe-area handling.

The artwork is adapted from the existing reference-derived project artwork, not third-party asset packs. Activity animation is still an initial sprite implementation and is not a fully rigged game animation system. On Samsung, lock screen availability depends on the wallpaper picker. The v0.2 world starts fresh because walkable anchors changed. Debug APKs may need a fresh install if signing keys differ.

Install the APK from Releases. GitHub Actions runs the simulation and interaction tests before publishing.
